# odin-recipes

## Decription

This is an exercise from The Odin Project meant to practice basic html. There should be the following:

- A folder called 'recipes' containing pages such as 'lasagna.html'.
- Boilerplate html in every .html file
- The recipe name in a heading
- An 'index.html' page with links to your recipes
- Links back to the index page
- Each recipe page should have an image of the finished dish, a description heading followed by a paragraph or two describing the recipe
- Ingredients list as an unordered list
- Steps as an unordered list
